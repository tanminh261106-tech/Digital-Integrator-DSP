\# Digital-Integrator-DSP



\## Overview

This project implements a Digital Integrator for Digital Signal Processing (DSP) using Verilog/SystemVerilog HDL.



\## Objectives

\- Implement the digital integrator RTL.

\- Verify the design using a testbench.

\- Simulate the design with ModelSim.

\- Document the architecture and simulation results.



\## Repository Structure



\- `rtl/`: RTL source code.

\- `tb/`: Testbench and verification code.

\- `sim/`: ModelSim simulation scripts.

\- `docs/`: Project report and presentation outline.

\- `results/`: Selected simulation logs and waveform evidence.



\## Requirements

\- Windows.

\- ModelSim Intel FPGA Starter Edition 2020.1 or a compatible simulator.

\- Git for Windows (for version control).



\## Simulation Instructions

1\. Clone or download this repository.

2\. Open ModelSim.

3\. Change the working directory to the repository root.

4\. Run the simulation script:



```tcl

do sim/run.do

```



5\. Check the Transcript for errors and the testbench results.

6\. Inspect the waveform signals.



\## Verification

The design must be verified against the expected behavior and test cases specified by the project requirements.
